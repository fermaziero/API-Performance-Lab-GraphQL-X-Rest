    08

    Leitura do resultado

    Texto gerado a partir dos números medidos nesta execução.

    Metodologia. Medições em loopback (localhost), na mesma máquina, com banco de dados local, e cliente e servidor no mesmo processo. CPU e memória alocada são do processo inteiro, sem separar cliente de servidor. O resultado descreve este padrão de acesso, nesta configuração e nesta máquina: não é um veredito geral sobre REST ou GraphQL.
